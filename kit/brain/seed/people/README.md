# people/

Une fiche par personne avec qui le propriétaire travaille, à plat : `people/prenom-nom.md` (minuscules, sans accents), à partir de [`kit/brain/templates/_PERSON-TEMPLATE.md`](../../kit/brain/templates/_PERSON-TEMPLATE.md). Prénom **et** nom obligatoires : sans nom de famille confirmé, citer la personne dans la mission et poser la question. Avant de créer une fiche, chercher alias et variantes dans les fiches existantes.

Contenu professionnel seulement (rôle, périmètre, attentes, façon de travailler), chaque ajout avec sa source datée. Pas de vie privée, santé, opinions ni téléphone. Les fiches de personnes qui ne sont plus actives vont dans [`archive/`](archive/README.md).
