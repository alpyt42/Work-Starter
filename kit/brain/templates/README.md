# Modèles

Copier le modèle adapté à sa destination, puis supprimer les consignes, exemples et sections facultatives vides.

- [`_CLIENT-TEMPLATE.md`](_CLIENT-TEMPLATE.md) → `projects/clients/<client>/<client>.md`
- [`_MISSION-TEMPLATE.md`](_MISSION-TEMPLATE.md) → `projects/clients/<client>/missions/<mission>/<mission>.md`
- [`_ACTIONS-TEMPLATE.md`](_ACTIONS-TEMPLATE.md) → `<projet>/state/actions.md`
- [`_DECISIONS-TEMPLATE.md`](_DECISIONS-TEMPLATE.md) → `<projet>/state/decisions.md`
- [`_SOURCES-INDEX-TEMPLATE.md`](_SOURCES-INDEX-TEMPLATE.md) → `<mission>/sources/YYYY-MM/index.md`
- [`_CR-TEMPLATE.md`](_CR-TEMPLATE.md) → `<mission>/sources/YYYY-MM/YYYY-MM-DD-cr-<slug>.md`
- [`_PROJECT-TEMPLATE.md`](_PROJECT-TEMPLATE.md) → `projects/internal/<projet>/<projet>.md`
- [`_NOTE-TEMPLATE.md`](_NOTE-TEMPLATE.md) → `<projet>/notes/YYYY-MM-DD-<sujet>.md`
- [`_PERSON-TEMPLATE.md`](_PERSON-TEMPLATE.md) → `people/<prenom-nom>.md`
- [`_HANDOFF-TEMPLATE.md`](_HANDOFF-TEMPLATE.md) → `<projet>/handoffs/YYYY-MM-DD-handoff-<slug>.md`
- [`templater/nouvelle-action.md`](templater/nouvelle-action.md) est exécuté par le bouton **Nouvelle action** de `tasks.md` ; il ne se copie pas dans une note.
