# Templates

Copy the template that fits its destination, then delete the instructions, examples and empty optional sections.

- [`_CLIENT-TEMPLATE.md`](_CLIENT-TEMPLATE.md) → `projects/clients/<client>/<client>.md`
- [`_MISSION-TEMPLATE.md`](_MISSION-TEMPLATE.md) → `projects/clients/<client>/missions/<mission>/<mission>.md`
- [`_ACTIONS-TEMPLATE.md`](_ACTIONS-TEMPLATE.md) → `<project>/state/actions.md`
- [`_DECISIONS-TEMPLATE.md`](_DECISIONS-TEMPLATE.md) → `<project>/state/decisions.md`
- [`_SOURCES-INDEX-TEMPLATE.md`](_SOURCES-INDEX-TEMPLATE.md) → `<mission>/sources/YYYY-MM/index.md`
- [`_CR-TEMPLATE.md`](_CR-TEMPLATE.md) → `<mission>/sources/YYYY-MM/YYYY-MM-DD-cr-<slug>.md` (`cr` = meeting minutes)
- [`_PROJECT-TEMPLATE.md`](_PROJECT-TEMPLATE.md) → `projects/internal/<project>/<project>.md`
- [`_NOTE-TEMPLATE.md`](_NOTE-TEMPLATE.md) → `<project>/notes/YYYY-MM-DD-<topic>.md`
- [`_PERSON-TEMPLATE.md`](_PERSON-TEMPLATE.md) → `people/<first-last>.md`
- [`_HANDOFF-TEMPLATE.md`](_HANDOFF-TEMPLATE.md) → `<project>/handoffs/YYYY-MM-DD-handoff-<slug>.md`
- [`templater/new-action.md`](templater/new-action.md) is run by the **New action** button of `tasks.md`; it is not copied into a note.
