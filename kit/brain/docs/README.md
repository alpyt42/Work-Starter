# docs/

The detailed references of the memory, to open when needed; the rules that are always useful stay in [`AGENTS.md`](../AGENTS.md).

- [`CONVENTIONS.md`](CONVENTIONS.md) — creating and filing sources, notes, workstreams, actions, decisions, people, handoffs and archives.
- [`WORKFLOWS.md`](WORKFLOWS.md) — inbox, focus, maintenance passes and end of session.
- [`GIT.md`](GIT.md) — commits, Git identities, publishing.
- `LOCAL-WORKFLOWS.md`, in the `docs/` of each brain — private paths and settings specific to that brain.
- [`REPOSITORIES.md`](REPOSITORIES.md) — private catalogue of client Git URLs.
- [`templates/`](../templates/README.md) — page templates and the Obsidian form for creating an action.
- `seed/` — files copied once into a new brain by `uv run tools/brain/new-brain.py <folder>` (options `--scope`, `--description`, `--remote`, `--email` to fill in `.data/brain.json`).
