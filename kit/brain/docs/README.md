# docs/

Les références détaillées de la mémoire, à ouvrir au bon moment ; les règles toujours utiles restent dans [`AGENTS.md`](../AGENTS.md).

- [`CONVENTIONS.md`](CONVENTIONS.md) — création et rangement des sources, notes, workstreams, actions, décisions, personnes, handoffs et archives.
- [`WORKFLOWS.md`](WORKFLOWS.md) — inbox, pilotage, passes de maintenance et fin de session.
- [`GIT.md`](GIT.md) — commits, identités Git, publication.
- `LOCAL-WORKFLOWS.md`, dans le `docs/` de chaque brain — chemins privés et réglages propres à ce brain.
- [`REPOSITORIES.md`](REPOSITORIES.md) — catalogue privé des URLs Git client.
- [`templates/`](../templates/README.md) — modèles de fiches et formulaire Obsidian de création d'action.
- `seed/` — fichiers copiés une fois dans un nouveau brain par `uv run tools/brain/new-brain.py <dossier>` (options `--scope`, `--description`, `--remote`, `--email` pour remplir `.data/brain.json`).
