            Keyboard shortcuts
            
      
            
        
            /
            Search or filter
            
        
            n
            New action
            
        
            1 to 6
            Today, Actions, Board, Timeline, Notes, Search
            
        
            j k or ↓ ↑
            Next or previous action
            
        
            ← → ↑ ↓
            On the Timeline: by date, and by project
            
        
            Alt ← →
            On the Timeline: move the deadline by a day (with Shift, a week)
            
        
            Enter
            Open the details
            
        
            s
            Change the status of the selected action
            
        
            d
            Change its due date
            
        
            Esc
            Close the panel or the menu
            
        
            ⌘ Enter
            Save the panel or the note
            
        
            ⌘ Z
            Undo the last write (outside a field)
            
        
            ⌘ B I U K
            In a note: bold, italic, underline, link (⇧ X: strikethrough)
            
        
            [
            Show or hide the sidebar
            
        
            ?
            This help
            
      
            
      
            Single-key shortcuts do not apply while you type. On Windows and Linux, Ctrl replaces ⌘.
