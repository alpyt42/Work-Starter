        Raccourcis clavier
        
      
        
        
        /
        Rechercher ou filtrer
        
        
        n
        Nouvelle action
        
        
        1 à 5
        Aujourd’hui, Actions, Tableau, Notes, Recherche
        
        
        j k ou ↓ ↑
        Action suivante ou précédente
        
        
        Entrée
        Ouvrir le détail
        
        
        s
        Changer le statut de l’action choisie
        
        
        d
        Changer son échéance
        
        
        Échap
        Fermer le panneau ou le menu
        
        
        ⌘ Entrée
        Enregistrer le panneau ou la note
        
        
        ⌘ Z
        Annuler la dernière écriture (hors d’un champ)
        
        
        [
        Afficher ou masquer la barre latérale
        
        
        ?
        Cette aide
        
      
        
      
        Les raccourcis à une touche ne s’appliquent pas pendant la saisie. Sur Windows et Linux, Ctrl remplace ⌘.
