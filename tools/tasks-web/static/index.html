        Keyboard shortcuts
        
      
        
        
        /
        Search or filter
        
        
        n
        New action
        
        
        1 to 5
        Today, Actions, Board, Notes, Search
        
        
        j k or ↓ ↑
        Next or previous action
        
        
        Enter
        Open the details
        
        
        s
        Change the status of the selected action
        
        
        d
        Change its due date
        
        
        Esc
        Close the panel or the menu
        
        
        ⌘ Enter
        Save the panel or the note
        
        
        ⌘ Z
        Undo the last write (outside a field)
        
        
        [
        Show or hide the sidebar
        
        
        ?
        This help
        
      
        
      
        Single-key shortcuts do not apply while you type. On Windows and Linux, Ctrl replaces ⌘.
